# ستوديو الكوفي — مواقع جاهزة لأصحاب الكوفيهات

مشروع لإنشاء مواقع إلكترونية جاهزة التخصيص وبيعها لأصحاب الكوفيهات. يضم ثلاثة نماذج مواقع كاملة بهويات بصرية مختلفة تماماً، بالإضافة إلى صفحة عرض (catalog) تُستخدم كواجهة تسويقية للمشروع نفسه.

## البنية

```
index.html, style.css, script.js     صفحة العرض (تسوّق النماذج الثلاثة وتشرح الأسعار وآلية العمل)
assets/previews/                     لقطات شاشة للنماذج الثلاثة تُستخدم في صفحة العرض
templates/
  rustic-cafe/     "ركن الحطب"  — هوية دافئة تقليدية (بني/كريمي/تراكوتا)
  modern-cafe/     "أثر"        — هوية بسيطة عصرية (أبيض/أسود/زمردي)
  luxury-cafe/     "ليالي"      — هوية فاخرة ليلية (داكن/ذهبي)
```

كل نموذج داخل `templates/` مستقل تماماً: `index.html` + `style.css` + `script.js` + مجلد `images/` (صور بديلة SVG محلية بدون أي اعتماد على خدمات خارجية). كل نموذج صفحة واحدة (single page) تضم: هيدر بقائمة تنقّل متجاوبة، قسم رئيسي (Hero)، قصة الكوفي، قائمة أسعار مقسّمة بتبويبات، معرض صور، ساعات العمل والموقع، وفوتر.

## التقنية

HTML / CSS / JavaScript خالص بدون أي إطار عمل أو أدوات بناء. يفتح أي ملف `index.html` مباشرة في المتصفح، أو يُرفع كما هو على أي استضافة استاتيكية.

## تخصيص نموذج لعميل جديد

1. انسخ مجلد النموذج المطلوب من `templates/`.
2. بدّل الاسم/الشعار النصي في الهيدر والفوتر، ونصوص القسم الرئيسي.
3. حدّث القائمة والأسعار وأوقات الدوام والعنوان ووسائل التواصل.
4. استبدل ملفات `images/*.svg` بصور حقيقية للكوفي (تحتفظ بنفس الأسماء والأبعاد لأسهل استبدال).
5. اربط خريطة Google Maps الفعلية مكان الصندوق المخصص `[مكان مخصص لخريطة Google Maps]`.

## تحديث لقطات صفحة العرض

بعد تعديل أحد النماذج، أعد التقاط لقطة الشاشة الخاصة به وضعها في `assets/previews/<اسم-النموذج>.png` ليعكسها قسم "النماذج" في `index.html`.
