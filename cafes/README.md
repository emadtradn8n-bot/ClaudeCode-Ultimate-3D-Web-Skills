# خمسة مقاهي

خمسة مواقع كوفي عربية (RTL)، كل واحد علامة مستقلة بهويتها البصرية ونموذج
تفاعلها. React + TypeScript + Vite + Tailwind v4، مساحة عمل واحدة و`node_modules`
مشترك، وكل موقع مدخل مستقل بلا راوتر.

```bash
npm install
npm run dev      # http://localhost:5210
npm run build
```

| الموقع | الشخصية | نموذج التفاعل | الخطوط |
|---|---|---|---|
| `/nasma/` **النسمة** | محمصة، غرفة داكنة دافئة، أخضر مريمية | السكرول يقود حقل تيارات هواء على canvas | Aref Ruqaa + IBM Plex Sans Arabic |
| `/rumman/` **رمّان** | بار عصائر مبهج، لون مختلف لكل مشروب | كاروسيل يعيد طلاء الصفحة بالكامل عند كل دورة | Lalezar + Tajawal |
| `/misk/` **مِسك** | مقهى نهاري فاتح، جبس ووردي مكتوم | شاشة واحدة، محتوى مثبّت للأسفل، بطاقات زجاجية | Amiri + Almarai |
| `/raseef/` **الرصيف** | مقهى رصيف وثائقي، أبيض وأسود | المؤشر يبدّل بين لقطتَي صباح ومساء، ثم لوح أسود يرتفع إلى معرض | Noto Kufi Arabic + IBM Plex Sans Arabic |
| `/ghaim/` **غَيْم** | قهوة مختصة، لؤلؤ سحابي وكراميل ذهبي | مشهد ثلاثي الأبعاد حيّ: كوب زجاجي وحلقة كراميل، والكاميرا تنزلق مع التمرير | El Messiri + Noto Sans Arabic |

الخمسة لا تشترك إلا في البنية: `src/shared/` فيه مصنع `Photo` ودوال الرسم
المشتركة. كل ما عدا ذلك — الألوان، الخطوط، القائمة، الحركة — مستقل تماماً.

## غَيْم — ملاحظات على المشهد ثلاثي الأبعاد

الوحيد الذي يبني مشهداً حقيقياً بدل رسم canvas ثنائي: React Three Fiber مع
drei و`@react-three/postprocessing` و GSAP ScrollTrigger. ثلاثة قرارات فيه
جاءت من أعطال حقيقية لا من ذوق، وكلّها موثّقة في `src/ghaim/scene/Scene.tsx`:

- **لا `AdaptiveDpr`.** يخفّض نسبة البكسل عند هبوط الأداء، وأهداف عرض
  `EffectComposer` لا تنجو من التحجيم فيخرج الإطار أسود. ولأنه لا ينشط إلا حين
  يتباطأ العرض، كان العطب يصيب الأجهزة الضعيفة وحدها.
- **`MeshTransmissionMaterial` على الكوب فقط.** الخامة تحجز هدف عرض خاصاً بها
  وتُعيد رسم المشهد لكل مجسّم يحملها. مكعّبات الثلج تستخدم `transmission`
  المدمج في `meshPhysicalMaterial` الذي يتشارك هدفاً واحداً.
- **الخلفية داخل المشهد لا في CSS.** لوح مصمت خلف كل شيء يمنح خامات الإرسال
  سطحاً تكسره فعلاً بدل لون بديل مفروض، ويمنع الضبابات من المزج نحو الأسود.

`<Environment>` مبنية من `<Lightformer>` لأن الإعدادات الجاهزة تنزّل HDRI من
شبكة خارجية محجوبة هنا، فيسقط الانعكاس بصمت ويصبح الزجاج باهتاً.

## الخطوط

محمّلة ذاتياً في `public/fonts/<cafe>.css` كـ base64 woff2 (المجموعة العربية
واللاتينية فقط). السبب أن `fonts.googleapis.com` محجوب عن المتصفح في هذه البيئة،
والربط الخارجي كان يسقط بصمت إلى خط احتياطي.

**ملاحظة على الطباعة العربية:** لا تضع `letter-spacing` على نص عربي — الخط
العربي متصل، والتباعد يفصل الحروف عن بعضها. التباعد مستخدم فقط على المقاطع
اللاتينية والأرقام.

## الصور

**لا توجد صورة وهمية في أي موقع.** كل صورة تشير إلى خانة معرّفة في
`src/<cafe>/assets.ts`. طالما ما في ملف حقيقي، يرسم `Photo` لوحة مؤطّرة تسمّي
اللقطة المطلوبة وتكتب "بانتظار الصورة".

### لتعبئة الصور

ضع الملفات في `public/photos/<cafe>/` بأسماء تطابق معرّفات الخانات، ثم:

```bash
python3 scripts/sync_photos.py           # كل المقاهي
python3 scripts/sync_photos.py nasma     # مقهى واحد
```

السكربت يربط الموجود ويطبع الناقص. الامتداد وحالة الأحرف لا تفرق.

معرّفات الخانات المستخدمة (تختلف من مقهى لآخر — راجع `assets.ts` لكل واحد):

```
cappuccino  latte-art  americano  espresso
iced-spanish-latte  iced-americano  orange-juice
cheesecake  chocolate-cake  blueberry-muffin
hero  interior  bar  barista  beans  overview
```

## إمكانية الوصول

كل حركة تحترم `prefers-reduced-motion`: خلفية النسمة ترسم إطاراً ثابتاً، وانتقالات
رمّان ومِسك تتقلّص إلى ١ms، والرصيف يتوقف عن تبديل اللقطات.
